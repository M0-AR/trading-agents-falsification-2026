🌱 Beginner guide (60 seconds per idea)

1. Prices
AAPL $183 → $181 → $170. Everything starts here.
2. Backtest
"What if I followed my rule in the past?" Replay day by day.
3. No peeking
Decide today with data ≤ today only. We enforce it in code.
4. Indicators
SMA trend, RSI heat, MACD flip, Bollinger tunnel, ATR jumpiness.
5. Only 3 numbers
Return (money), Sharpe (wobble-adjusted), Drawdown (worst fall).
6. Costs kill
15 trades at 50bps: +15% → −1.2%.
7. Count tries
Best-of-100 looks great by luck. Deflate it.
8. One run ≠ truth
14–30% disagreement → need 7-of-10 agreement.
